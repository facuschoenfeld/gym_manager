# Reportes

Informes generados por el subagente `report-writer` después de cada subagente (`ui-ux-reviewer`, `code-reviewer`, `test-runner`, `researcher`, `security-auditor`) y al cerrar cada fase.

**Nombre de archivo:** `AAAA-MM-DD_HHMM_<subagente>_<tema-corto>.md`

Ejemplos:
- `2026-11-03_1015_ui-ux-reviewer_pantalla-socios.md`
- `2026-11-03_1140_code-reviewer_alta-socio.md`
- `2026-11-05_1800_fase-2_cierre.md`

La regla completa está en la sección "Automatización de subagentes" de [`CLAUDE.md`](../CLAUDE.md).
